# NewsNLI Website

This repository contains the official website for **NewsNLI**, an open-source initiative focused on building a high-quality Natural Language Inference (NLI) dataset for the news domain.

The website serves as the primary entry point for the project, providing information about the initiative, contribution process, and application form for prospective contributors.

## Tech Stack

The website is built using HTML, CSS, and hosted using GitHub Pages.

## Local Development

Clone the repository:

```bash
git clone https://github.com/aj11anuj/newsnli-site.git
```

Open `index.html` in your browser, or use a local web server such as:

```bash
python -m http.server
```

Then visit:

```
http://localhost:8000
```
